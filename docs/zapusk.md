# Запуск

## Бэкенд (делает владелец, один раз)
1. Новый проект Apps Script, вставить `apps-script/Code.gs`, часовой пояс Europe/Moscow.
2. Запустить `setupSpreadsheet`, разрешить доступ к таблицам.
3. Настройки проекта → Свойства скрипта: `ADMIN_PIN` (4–12 цифр).
4. Развернуть → Веб-приложение: от имени владельца, доступ «Все». Адрес `/exec` вписать в `game/public/config.json` и поставить `"useMock": false`.

## Админка, до 9:00 26.11
1. «РГ и планы»: дата 26.11.2026, имена, группы ровно как в файле, планы.
2. «Пары»: проверить.
3. «Доступ»: PIN всем РГ (показываются один раз), ключ экрана; ссылку открыть на каждом экране и один раз нажать на звук.
4. «Анимации»: пробный удар и раунд.

Порядок РГ в админке задаёт бойца: 1 зелёный счетовод, 2 грозовой курьер, 3 солнечный курьер, 4 литейщик, 5 стальной экспедитор, 6 ворон.

## День игры
РГ вносят оплаты на `rg.html`. Раунды сами в 10:00, 12:00, 15:00. 27.11 в 13:00: «Импорт» → файл → проверить разницу → «Загрузить и запустить Final Round». Ошиблись файлом: «Отменить итог».

## Локально
`npm run mock-backend` и `npm run dev` в `game/`: `http://127.0.0.1:8080/?backend=http://127.0.0.1:8787/exec#key=mock-key`.
